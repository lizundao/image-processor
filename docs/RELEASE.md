# 图片处理器 — 发布说明

> 版本：**1.0.0** · 作者：**inkdot** · 官网：[inkdot.cn](https://inkdot.cn)

本文档面向最终用户，包含软件介绍、使用教程与常见问题，可直接用于官网发布、下载页说明或压缩包附带的文档。

## 一、软件介绍

**图片处理器**是一款面向 Windows 的离线桌面批量图片处理工具。所有图片处理均在您的电脑本地完成，**无需联网、不上传文件**，适合日常办公、电商素材、社交媒体配图等场景。

### 核心特点

| 特点 | 说明 |
|------|------|
| **完全离线** | 处理过程不依赖网络，保护隐私 |
| **批量处理** | 一次导入多张图片，统一参数批量输出 |
| **功能丰富** | 压缩、水印、转换、裁剪、合并等 14 种功能 |
| **开源许可** | 依据 MIT 开源许可提供，当前版本可自由使用 |
| **开源许可** | MIT 许可证，可自由使用 |

### 功能一览

| 功能 | 说明 |
|------|------|
| 图片压缩 | JPEG / PNG / WebP 等，PNG 支持色彩量化 |
| 添加水印 | 文字水印（系统字体）或图片水印，可调位置与透明度 |
| 格式转换 | JPEG、PNG、WebP、GIF、BMP、TIFF、ICO |
| 调整尺寸 | 等比缩放，指定宽度或高度 |
| 图片裁剪 | 比例裁剪、像素裁剪、手动框选裁剪 |
| 图片旋转 | 任意角度旋转 |
| 图片翻转 | 水平 / 垂直翻转 |
| 亮度调整 | 调亮或调暗 |
| 添加边框 | 实线 / 虚线 / 点线，可调颜色与宽度 |
| 设置圆角 | 统一圆角半径 |
| 合并图片 | 水平或垂直拼接，可调间距 |
| 合成 GIF | 多图按顺序合成动画 |
| 一键美化 | 自动曝光、白平衡、对比度、锐化 |
| 宫格切图 | 等分切割，适合头像、九宫格等 |

### 技术说明

- 基于 **Tauri + Rust** 构建，处理速度快、占用资源少
- 界面支持**中文 / 英文**，**浅色 / 深色 / 跟随系统**主题
- 安装版与免安装版功能完全一致

## 三、下载与安装

提供两种 Windows 版本，任选其一即可。

### 方式 A：免安装便携版（推荐快速体验）

1. 下载 `ImageProcessor-1.0.0-portable-win-x64.zip`
2. 解压到任意目录，例如 `D:\Tools\ImageProcessor\`
3. 双击 **`image-processor.exe`** 运行（Tauri 2 已将运行资源内嵌到单个 exe，无需额外资源目录）

```
ImageProcessor-1.0.0-portable-win-x64/
├── image-processor.exe   ← 主程序（资源已内嵌）
├── RELEASE.md            ← 发布说明
└── LICENSE               ← 许可文件
```

**便携版优点**：不写注册表、不安装到 Program Files，可放 U 盘随身携带。  
**说明**：Tauri 2 已将运行所需资源内嵌到单个 `image-processor.exe`，单独复制 exe 即可运行；建议一并保留 `RELEASE.md` 与 `LICENSE`。

### 方式 B：安装版

| 格式 | 文件名示例 | 说明 |
|------|------------|------|
| NSIS 安装程序 | `ImageProcessor-1.0.0-setup-win-x64.exe` | 常规用户推荐，双击安装向导即可（当前用户安装，免管理员权限） |

安装版默认安装路径（英文目录）：

```
C:\Program Files\ImageProcessor\
```

安装完成后可从开始菜单或桌面快捷方式启动。卸载请使用「设置 → 应用 → 已安装的应用」或控制面板。

## 四、快速上手（5 分钟教程）

### 第 1 步：设置输出目录

首次使用前**必须**指定图片保存位置：

1. 点击顶部菜单 **设置(S) → 输出设置...**
2. 点击 **选择目录**，或手动输入路径（如 `D:\Pictures\Output`）
3. 点击 **保存设置**

> 未设置输出目录时，点击「开始处理」会提示错误。

### 第 2 步：添加图片

任选一种方式：

- **拖放**：将图片文件拖入窗口中央或右侧列表区域
- **点击添加**：在图片列表区域点击「选择图片文件」
- **菜单**：**文件(F) → 打开**（若可用）

支持格式：JPEG、PNG、GIF、BMP、WebP 等常见图片格式。

### 第 3 步：选择功能并调整参数

1. 在左侧 **功能导航** 中选择需要的功能（默认「图片压缩」）
2. 在中间 **参数面板** 调整选项，例如压缩质量、水印文字等
3. 右侧可预览已添加的图片列表，支持拖拽排序（GIF 合成时顺序很重要）

### 第 4 步：开始处理

1. 点击右侧工具栏 **开始处理**
2. 等待进度完成（每张图片会显示处理状态）
3. 若开启了「自动打开输出文件夹」，处理完成后会自动打开结果目录

### 界面布局示意

```
┌─────────────────────────────────────────────────────────┐

```

## 五、功能教程

### 5.1 图片压缩

1. 选择 **图片压缩**
2. 拖动 **质量** 滑块（越高越清晰、文件越大，建议 70–85）
3. 添加图片 → **开始处理**

输出可在全局设置中指定为 JPEG / PNG / WebP，或勾选「保持原格式」。

### 5.2 添加水印

**文字水印：**

1. 选择 **添加水印** → 类型选「文字水印」
2. 输入水印文字，选择系统字体、大小、颜色
3. 设置位置（如右下角）、透明度、边距
4. 开始处理

**图片水印：**

1. 类型选「图片水印」
2. 点击选择水印图片文件
3. 调整缩放比例、位置与透明度

### 5.3 格式转换

1. 选择 **格式转换**
2. 选择目标格式（JPEG / PNG / WebP / GIF / BMP / TIFF / ICO）
3. 有损格式可设质量；PNG 可设压缩级别
4. 可选：保留透明度、替换透明背景色

### 5.4 调整尺寸

1. 选择 **调整尺寸**
2. 填写目标 **宽度** 或 **高度**（填一项即可，另一项等比计算）
3. 留空则不改变该维度

### 5.5 图片裁剪

支持三种模式：

| 模式 | 适用场景 |
|------|----------|
| 比例裁剪 | 固定宽高比（如 1:1 头像、16:9 封面） |
| 像素裁剪 | 指定输出像素尺寸 |
| 手动裁剪 | 在预览图上框选区域 |

手动裁剪模式下，可逐张调整裁剪框。

### 5.6 旋转与翻转

- **旋转**：输入角度（如 90、180、-45）
- **翻转**：勾选水平 / 垂直翻转

### 5.7 亮度调整

拖动亮度滑块，负值变暗，正值变亮。建议小幅调整（±20 以内）以免过曝或失真。

### 5.8 边框与圆角

- **边框**：设置宽度、颜色、线型（实线 / 虚线 / 点线）、透明度
- **圆角**：设置统一圆角半径（像素）

### 5.9 合并图片

1. 按期望顺序添加多张图片（可拖拽排序）
2. 选择 **合并图片**
3. 选择水平或垂直方向，设置图片间距（0 为无缝）

### 5.10 合成 GIF

1. 按帧顺序添加图片（**顺序即播放顺序**）
2. 选择 **合成 GIF**
3. 设置帧率（FPS）、循环次数（0 = 无限循环）、质量
4. 开始处理

### 5.11 一键美化

1. 选择 **一键美化**
2. 调整美化强度，勾选自动曝光、白平衡、局部对比度、锐化等选项
3. 可点击 **打开预览** 对比效果后再批量处理

### 5.12 宫格切图

1. 选择 **宫格切图**
2. 设置行数 × 列数（如 3×3），或使用快速预设
3. 设置输出格式与命名模式（如 `grid_{row}_{col}`）
4. 一张图会被切成多块分别保存

## 六、全局设置说明

通过菜单 **设置(S)** 可打开各项全局设置：

### 输出设置

| 选项 | 说明 |
|------|------|
| 输出目录 | 处理后文件的保存路径（必填） |
| 输出格式 | 默认输出格式，或「保持原格式」 |
| 质量 | 默认压缩 / 转换质量（1–100） |
| 文件名模式 | 支持变量，见下表 |
| 覆盖现有文件 | 同名文件是否覆盖 |
| 创建子文件夹 | 按功能类型分子目录（如 `compressed\`） |

**文件名模式可用变量：**

| 变量 | 含义 | 示例 |
|------|------|------|
| `{name}` | 原文件名（不含扩展名） | `photo` |
| `{timestamp}` | 时间戳 | `20250608143022` |
| `{index}` | 序号 | `001` |

示例模式：`{name}_{timestamp}` → `photo_20250608143022.jpg`

### 行为设置

- **自动打开输出文件夹**：处理完成后自动打开资源管理器到输出目录

### 语言与主题

- **语言**：简体中文 / English
- **主题**：浅色、深色、跟随系统

设置会自动保存，下次启动生效。

## 八、常见问题（FAQ）

### Q1：双击程序没有反应？

**可能原因与解决办法：**

1. **缺少 WebView2 运行时**  
   前往 [WebView2 下载页](https://developer.microsoft.com/microsoft-edge/webview2/) 安装「Evergreen Bootstrapper」或「Evergreen Standalone Installer」。

2. **便携版文件不完整**  
   确认 zip 已完整解压；Tauri 2 已将运行资源内嵌到单个 `image-processor.exe`，无需额外资源目录。

3. **杀毒软件拦截**  
   本软件未做代码签名，部分杀毒软件可能误报。可添加信任或暂时关闭实时防护后重试。

### Q2：提示「请先设置输出目录」？

打开 **设置 → 输出设置**，选择或输入一个有效的文件夹路径并保存。输出目录必须存在或可创建，且应用有写入权限。

### Q3：处理失败或部分图片失败？

- 确认图片未损坏，格式受支持
- 检查输出目录磁盘空间是否充足
- 若未勾选「覆盖现有文件」，同名文件会被跳过
- 路径中尽量避免特殊字符；输出目录建议用英文路径

### Q4：水印中文显示为方框？

请选择系统中已安装的中文字体（如微软雅黑、宋体）。若字体列表为空，请重启程序；仍无效请检查系统字体是否完整。

### Q5：GIF 合成顺序不对？

GIF 按图片列表**从上到下**的顺序合成。请在右侧列表中拖拽调整顺序后再处理。

### Q6：压缩后反而变大了？

以下情况可能出现体积增大：

- 原图已是高度压缩的 JPEG，再转 PNG 或提高质量
- 原图尺寸很小，重新编码的元数据开销占比高  

建议：压缩时适当降低质量，或保持原格式输出。

### Q7：便携版和安装版有什么区别？

| 对比项 | 便携版 | 安装版 |
|--------|--------|--------|
| 安装步骤 | 解压即用 | 运行安装向导 |
| 注册表 | 不写 | 写入卸载信息 |
| 快捷方式 | 需自行创建 | 自动创建 |
| 功能 | 相同 | 相同 |
| 卸载 | 删除文件夹即可 | 系统「卸载程序」 |

### Q8：可以多开吗？

可以。便携版复制多份到不同文件夹即可多开；安装版可多次运行 exe（注意输出目录不要冲突）。

### Q9：设置存在哪里？

应用数据保存在系统用户目录（如 `%APPDATA%` 下与应用相关的文件夹），重装或换目录不影响已保存的设置。

### Q10：是否收费？需要联网吗？

依据 **MIT 开源许可**提供，当前版本可自由使用，允许个人与商业使用，具体以 MIT 许可条款为准。日常使用**不需要联网**；仅在访问官网、查看帮助时需要网络。

### Q11：支持 macOS / Linux 吗？

当前发布包以 **Windows 64 位** 为主。macOS / Linux 需从源码自行构建，详见开发者文档 [BUILD.md](BUILD.md)。

### Q12：如何卸载？

- **安装版**：Windows「设置 → 应用 → 图片处理器 → 卸载」
- **便携版**：关闭程序后，直接删除整个文件夹即可
